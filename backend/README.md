# EMS Backend
Rest API for Employee Management System (EMS) built with FastAPI, SQLAlchemy, and SQLite (with further support for MySQL).

## Requirements
- Python 3.14 or higher
- FastAPI
- SQLAlchemy
- SQLite
- JWT for authentication
- uv package manager
- pytest for testing

## Structure
```backend
├── app
│   ├── core/
│   ├── models/
│   ├── routes/
│   ├── schemas/
│   ├── services/
│   └── main.py
├── tests/
├── .gitignore
└── README.md
```
